# El precio del desarrollo

Reportaje multimedia de Constanza Higueras Troncoso e Ignacia Vallejos Collipal.
Proyecto de título, Periodismo, Universidad Autónoma de Chile, 2026.

## Cómo publicarlo en GitHub Pages
1. Crear un repositorio nuevo (público) en GitHub.
2. Subir TODO el contenido de esta carpeta (index.html, css, js, img, fonts, planos, video), respetando las carpetas.
3. En el repositorio: Settings > Pages > Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`. Guardar.
4. En uno o dos minutos el sitio queda en https://USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/

Si ya existe un repositorio con la versión anterior: reemplazar los archivos por los de esta carpeta (index.html, css/, js/, img/, video/) y hacer commit.

## Estructura
- index.html: todo el texto del reportaje.
- css/styles.css: diseño y colores (paleta al inicio del archivo).
- js/main.js: menú, visor de planos, galerías ampliables y comparador "ahora / después".
- img/san-antonio, img/maule, img/buin: fotos, planos y las dos imágenes del comparador (ahora.jpg, despues.jpg).
- planos/: PDF originales del data center.
- video/: recorrido por el Humedal Ojos de Mar (San Antonio) y videos del terreno de Buin.
- fonts/: tipografías Big Shoulders Display y Newsreader (licencia SIL Open Font License).

Importante: no cambiar nombres de archivos ni carpetas; GitHub distingue mayúsculas y minúsculas.
